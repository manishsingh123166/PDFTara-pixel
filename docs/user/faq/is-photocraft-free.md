title: Is PDFTara Pixel free?
description: PDFTara Pixel is free and open source under the MIT or Apache 2.0 license, and works offline.

Yes. PDFTara Pixel is one of the Crafting Apps, which the project describes as free, open-source creative tools. The code is licensed under MIT or Apache 2.0, your choice, and is on [GitHub](https://github.com/storytold/PDFTara Pixel).

PDFTara Pixel works offline. Its smart selection tools run on your computer, with no cloud and no account.

The PDFTara pixel logos in the repository are not open source.

See [Install PDFTara Pixel](../getting-started/install.md) to download it.
